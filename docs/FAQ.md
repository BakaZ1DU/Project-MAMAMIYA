# FAQ / 常见问题

## 1. 日志说发布成功，但朋友圈没有？

先看 `logs/previews/<id>_filled_*.png`：

- 如果预览图里没有文案/图片：是填写阶段失败；
- 如果预览图正常，但朋友圈没有：检查 `logs/previews/photo_not_sent_*.png`。

v1.0.1 已修复“成功帖被误判为照片未发送”的问题。如果仍出现，请附：

- `logs/wxrobot.log`
- `logs/previews/` 对应截图
- 微信版本号

## 2. 微信提示“照片未发送”

先做手动对照：

1. 在微信里手动发一张本地图片到朋友圈；
2. 如果手动也失败，按顺序排查：
   - 手机微信保持在线，手机和电脑同一网络；
   - 换手机热点；
   - 完全退出微信再登录；
   - 手机微信 → 微信团队 / 微信安全中心，查看是否有朋友圈功能限制；
   - 换一张普通 jpg 照片（几 MB 内）。
3. 如果手动正常、只有程序失败：看 `photo_not_sent_*.png`，确认选中的是不是这条计划的图片。

> 账号被限制、图片上传通道不可用时，任何 UI 自动化都无法绕过。

## 3. 相机按钮点不开

程序会先把最大化窗口还原成普通窗口，因为最大化时右上角按钮在部分版本上点不动。

仍失败时：

- 确认朋友圈页面已经加载出内容（不是空白页）；
- 把微信窗口放在屏幕内，不要贴边/最小化；
- 用 `诊断启动.bat` 启动，查看 `no_file_dialog_*.png`；
- 微信大版本更新可能导致按钮位置变化，需要调整 `wechat_ui.py` 的候选坐标。

## 4. 选中的图片不对

程序会进入这条计划自己的 `图片/` 文件夹再全选，正常情况下不会选到上一次的图片。

如果你手动替换了 `图片/` 里的文件，请保持文件夹里只有这条计划的图片；不要放 `文案.txt`、`post.json` 等非图片文件。

## 5. 提示“已有未关闭的编辑框”

程序不会覆盖你正在编辑的草稿。请先在微信里：

- 手动发表，或
- 点“取消” → “不保留”。

然后再运行。

## 6. 电脑锁屏/睡眠

锁屏时 Windows 不允许模拟鼠标键盘，程序会跳过等待解锁。

程序默认会阻止系统睡眠，但不能阻止手动合盖/锁屏。建议发布时段保持电脑唤醒。

## 7. 重复双击启动

程序有单实例锁。重复双击会提示“已经在运行”，不会开第二个调度器。

## 8. 能不能发视频/链接/位置/@好友？

当前只支持图片 + 文案。其他类型需要额外 UI 自动化，未实现。

## 9. 能不能同时发多条？

同一时间只执行一个发布任务；队列里可以有多条，按时间顺序依次发。

## 10. 日志/截图在哪里？

```text
logs/wxrobot.log
logs/previews/
```

`previews` 里：

- `<id>_filled_*.png`：发布前编辑框；
- `photo_not_sent_*.png`：检测到照片未发送；
- `no_file_dialog_*.png`：相机/文件框没打开；
- `moments_not_ready_*.png`：朋友圈页面没加载。
