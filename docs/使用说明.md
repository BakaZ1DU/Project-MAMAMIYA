# wx_ROBOT 使用说明

## 1. 安装

1. 安装 **Python 3.12**（安装时勾选 “Add Python to PATH”）；
2. 安装依赖：

   ```bat
   python -m pip install -r requirements.txt
   ```

3. 复制配置模板：

   ```bat
   copy config.example.json config.json
   ```

4. 登录 Windows 微信 4.x，确认能手动打开“朋友圈”。

## 2. 启动

双击 `启动.bat`。

程序会：

- 创建 `待发布/`、`已发布/`、`失败/`、`已删除/`、`logs/`；
- 启动后台调度器（每 3 秒扫描一次队列）；
- 显示微信连接状态和“下一条”计划。

如果启动失败，双击 `诊断启动.bat` 看控制台错误。

## 3. 新建计划

1. 点“新建”；
2. 填发布时间，例如 `2026-10-30 08:30`（未来 24 小时内）；
3. 粘贴文案（最多 1500 字）；
4. 添加 1–9 张图片（jpg / png / bmp）；
5. 选择可见范围（公开 / 私密）；
6. 点“保存计划”。

图片会复制到计划目录，之后移动/删除原图不影响发布。

## 4. 第一次建议先“预览填充”

选中计划 → 点“预览填充（不发布）”。

程序会真实打开微信朋友圈编辑框，填入文案和图片，但不会点“发表”。你检查排版、图片顺序、可见范围后，在微信里点“取消” → “不保留”。

确认没问题后，再让它在设定时间自动发布。

## 5. 发布时注意

- 程序会短暂抢占鼠标/键盘，约 10–40 秒；
- 不要移动鼠标、切换窗口、锁屏；
- 微信必须在线，朋友圈页面能正常加载；
- 发布完成后，计划会移动到 `已发布/年-月/`。

## 6. 目录说明

```text
待发布/
  20261030_0830_晚霞/
    文案.txt
    图片/
      01_xxx.jpg
      02_xxx.jpg
    post.json
已发布/
失败/
已删除/
logs/
  wxrobot.log
  previews/
```

- `文案.txt` 可以直接用记事本修改；
- `post.json` 记录时间、状态、重试次数，不建议手改；
- `logs/previews/` 保存每次发布前和失败时的截图。

## 7. 状态与重试

| 状态 | 说明 |
|---|---|
| 草稿 | 不发布 |
| 待发布 | 到点自动发 |
| 发布中 | 正在操作微信 |
| 已发布 | 成功归档 |
| 失败 | 不可重试或重试次数用完 |
| 已跳过 | 超过补发窗口 |

- 普通错误（窗口没找到、文案没填进去）会按 `retry_delay_minutes` 重试；
- `照片未发送` 和“结果无法确认”不会自动重试，避免刷屏/重复发帖；
- 错过时间超过 `catch_up_minutes`（默认 90 分钟）会标记“已跳过”，不会发过期内容。

## 8. 可见范围

`config.json`：

```json
"privacy": "public"
```

- `public`：公开（所有朋友可见）
- `private`：私密（仅自己可见）

程序每次发布前都会主动选择，不依赖微信上一次的记忆。

## 9. 停止/退出

点窗口右上角关闭，确认退出；后台调度器会停止。

如果正在发布，建议等发布结束再退出，避免微信编辑框停在半途。

## 10. 数据与隐私

- 不保存微信密码；
- 不读取聊天记录；
- 队列和日志都在本地；
- `config.json` 可能包含你的微信路径/账号提示，建议不要提交到公开仓库（`.gitignore` 已忽略）。
